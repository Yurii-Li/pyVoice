# 🚀 Інструкція: Як випустити нову версію PyVoice AI

У проєкті налаштовано систему **автоматичного оновлення клієнтських додатків**.  
Після публікації релізу друзям та користувачам не потрібно заново перекачувати файли вручну — програма при запуску (або по кнопці в статус-барі `🔄 vX.X.X`) сама запропонує оновитися в 1 клік.

---

## 🛠️ Варіант 1: Повністю автоматичний випуск (через GitHub Actions) — Рекомендовано

Завдяки файлу `.github/workflows/release.yml`, хмарний сервер GitHub сам збирає Windows `.exe` та публікує його в Releases при пуші git-тегу.

### Крок 1. Змініть номер версії в коді
Відкрийте файл `src/pyvoice/__init__.py` і оновіть рядок версії:
```python
__version__ = "1.4.0"  # вкажіть ваш новий номер версії
```

### Крок 2. Зробіть коміт зі змінами
У терміналі:
```cmd
git add .
git commit -m "feat: опис головних змін цього релізу"
```

### Крок 3. Створіть git-тег та відправте на GitHub
Вкажіть тег із літерою `v` попереду (вона обов'язкова для спрацювання автоматизації):
```cmd
git tag v1.4.0
git push origin main --tags
```

### Що відбудеться далі:
1. GitHub Actions автоматично запуститься у вкладці **Actions** вашого репозиторію (`https://github.com/Yurii-Li/pyVoice/actions`).
2. Сервер розгорне чисту Windows, встановить Python, залежності, завантажить Whisper і збере `PyVoiceAI.exe` через PyInstaller.
3. Готовий файл автоматично прикріпиться до розділу **Releases** (`https://github.com/Yurii-Li/pyVoice/releases`).
4. Користувачі відкриють свій додаток і побачать пропозицію оновитися.

---

## 💻 Варіант 2: Ручний випуск (якщо збираєте `.exe` на власному комп'ютері)

Якщо ви хочете зібрати файл самостійно на своєму ПК:

### Крок 1. Підніміть версію в коді
У `src/pyvoice/__init__.py`:
```python
__version__ = "1.4.0"
```

### Крок 2. Зберіть проєкт у PyInstaller
Переконайтеся, що віртуальне оточення активоване, та запустіть збірку:
```cmd
python build.py
```
*(Готовий файл буде знаходитися у папці `dist/PyVoiceAI.exe`)*

### Крок 3. Створіть реліз на сайті GitHub
1. Відкрийте сторінку: **https://github.com/Yurii-Li/pyVoice/releases/new**
2. Натисніть **«Choose a tag»** → введіть `v1.4.0` → натисніть **«Create new tag»**.
3. Введіть назву релізу (Release title), наприклад: `PyVoice AI v1.4.0: Оновлення інтерфейсу та авто-оновлення`.
4. В поле опису додайте список змін для користувачів (вони відображатимуться у вікні оновлення програми).
5. Перетягніть файл `dist/PyVoiceAI.exe` у блок **«Attach binaries by dropping them here»**.
6. Натисніть зелену кнопку **«Publish release»**.

---

## 🔍 Як перевірити роботу автооновлення

1. Запустіть стару версію програми.
2. У правому нижньому кутку статус-бару натисніть кнопку **`🔄 v...`** або просто зачекайте 2 секунди після старту.
3. З'явиться віконце:
   * З назвою нової версії та описом змін.
   * Кнопка **«🚀 Оновити зараз»** завантажить файл з прогрес-баром, замінить старий `.exe` та автоматично перезапустить вже нову програму.

> ⚠️ **Зверніть увагу:**  
> Якщо ви тестуєте програму в режимі вихідного коду (`python run.py`), автозаміна `.exe` файлу вимкнена (щоб не зламати оточення розробника) — програма попередить про це і відкриє сторінку релізу в браузері. Автоматична заміна файлу спрацьовує виключно у зібраному `.exe`.
