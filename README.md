# PyVoice AI 🎬🎙️

**PyVoice AI** — портативний десктопний додаток для Windows, який автоматично аналізує дії у відео за допомогою **Google Gemini Vision AI**, створює детальний сценарій закадрової озвучки з точними таймкодами та монтує синхронізоване відео зі стоп-кадрами (**freeze frames**) через **Edge TTS** та **FFmpeg**.

---

## 🏛️ Архітектура проєкту (`src` Layout)

Проєкт побудовано за стандартом модульної архітектури Python:

```text
pyVoice/
├── src/
│   └── pyvoice/
│       ├── __init__.py            # Метадані та версія пакету
│       ├── main.py                # Головна точка входу пакету
│       │
│       ├── core/                  # Бізнес-логіка (не залежить від графічного інтерфейсу)
│       │   ├── config.py          # Робота з налаштуваннями config.json
│       │   ├── gemini.py          # Vision AI (завантаження та аналіз відео)
│       │   ├── tts.py             # Генерація голосу Edge TTS
│       │   ├── video.py           # Нарізка, стоп-кадри та склеювання (FFmpeg)
│       │   └── pipeline.py        # Загальний пайплайн обробки
│       │
│       ├── ui/                    # Графічний інтерфейс
│       │   └── app.py             # Візуальне вікно Tkinter, віджети та логи
│       │
│       └── utils/                 # Загальні утиліти
│           ├── paths.py           # Робота зі шляхами до FFmpeg / системних файлів
│           └── time_parser.py     # Конвертація таймкодів
│
├── scripts/
│   └── build.py                   # Скрипт збірки портативного .exe
│
├── run.py                         # Точка входу для швидкого запуску
├── requirements.txt               # Залежності
├── .gitignore                     # Правила виключення Git
└── README.md                      # Документація
```

## ✨ Основні можливості

- **👁️ Vision AI Аналіз Відео:** Нейромережа Gemini переглядає відеоряд і генерує сценарій озвучки з поясненням функціоналу, вступним привітанням та підсумком.
- **🎙️ Озвучка голосами Edge TTS:** Природні українські голоси (Остап / Поліна).
- **⏱️ Розумні стоп-кадри (Freeze Frames):** Якщо тривалість озвучки довша за дію на відео, програма автоматично «заморожує» останній кадр і чекає завершення репліки диктора.
- **📝 Вбудований редактор сценарію:** Перегляд та редагування згенерованих таймкодів і тексту прямо перед монтажем.
- **📦 Повна портативність:** Автономний `PyVoiceAI.exe` працює без встановлення додаткового ПЗ.

## 🛠️ Встановлення та запуск для розробки

1. **Клонування репозиторію:**
   ```powershell
   git clone https://github.com/Yurii-Li/pyVoice.git
   cd pyVoice
   ```

2. **Створення та активація віртуального оточення:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. **Запуск програми:**
   ```powershell
   python run.py
   ```

4. **Збірка портативного `.exe`:**
   ```powershell
   python scripts/build.py
   ```
   Готовий файл `PyVoiceAI.exe` з'явиться у папці `dist/`.
