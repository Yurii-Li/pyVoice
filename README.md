# PyVoice AI 🎬🎙️

**PyVoice AI** — портативний десктопний додаток для Windows, який автоматично аналізує дії у відео за допомогою **Google Gemini Vision AI**, створює детальний сценарій закадрової озвучки з точними таймкодами та монтує синхронізоване відео зі стоп-кадрами (**freeze frames**) через **Edge TTS** та **FFmpeg**.

---

## ✨ Основні можливості

- **👁️ Vision AI Аналіз Відео:** Нейромережа Gemini переглядає відеоряд і генерує сценарій озвучки з поясненням функціоналу, вступним привітанням та підсумком.
- **🎙️ Озвучка голосами Edge TTS:** Вибір природних українських голосів (Остап / Поліна).
- **⏱️ Розумні стоп-кадри (Freeze Frames):** Якщо тривалість озвучки довша за дію на відео, програма автоматично «заморожує» останній кадр потрібного фрагмента і чекає завершення репліки диктора.
- **📝 Вбудований редактор сценарію:** Можливість переглядати та редагувати згенеровані таймкоди й текст прямо у вікні програми перед монтажем.
- **📦 Повна портативність:** Збирається в один автономний `.exe` файл, який працює «з коробки» без встановлення Python чи додаткових програм.

---

## 🛠️ Встановлення та запуск для розробки

1. **Клонування репозиторію:**
   ```bash
   git clone <URL_РЕПОЗИТОРІЮ>
   cd pyVoice
   ```

2. **Встановлення залежностей:**
   ```bash
   pip install requests edge-tts pyinstaller
   ```

3. **Запуск програми:**
   ```bash
   python app.py
   ```

4. **Збірка портативного `.exe`:**
   ```bash
   python build.py
   ```
   Готовий файл `PyVoiceAI.exe` з'явиться у папці `dist/`.
